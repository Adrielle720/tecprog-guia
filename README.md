# Algoritmos em movimento · Técnicas de Programação

Guia de estudo interativo para a disciplina [Técnicas de Programação (Insper)](https://insper.github.io/TecProg/).

- Uma página por algoritmo (buscas, recursão, ordenação, DFS/BFS, grafos, backtracking) com depurador animado linha a linha, variações, erros comuns, perguntas e exercícios.
- `simulados.html`: todos os exercícios (escolha, rastreio, completar linhas, escrever código) com correção automática.
- O código Java roda no navegador por um interpretador próprio (`js/java.js`), validado contra o `javac`/`java` real (`tools/validar.js`, `tests/diferencial.js`).

Visual inspirado em [compiladores-guia](https://github.com/OscarRodriguesFilho/compiladores-guia), de Oscar Rodrigues Filho.
